### ER Diagram
- ER - Entity Relationship
- An ER Diagram is visual way to design a database before writing SQL coding.
- ER diagram is the blueprint of database design.
1) Entities - Tables
2) Attributes - Columns
3) Relationships - How tables connected to each other - One-to-One, One-to-Many, Many-to-Many
4) Keys - Primary key, Foreign key

#### Database / DBMS / Data Design
- 1) Data Design -> Structure/Planning
Planning of data structure
Blueprint of how data should be stored

- 2) DBMS (Database management sysytem) -> PostgreSQL, Oracle, MySQL = Software
Software to manage database
Tool to create, read, update, delete data

- 3) Database -> Stored data = Data
Collection of data
Actual stored data
