### For Day 2 we will start with List, Set, Tuple, Dictionary

- List :
1) List is written by []
2) In python list is ordered, mutable collection of elements.
   Common Operations: 
   a) append(), remove(), pop(), sort()
   b) min(), max(), sum()
3) List is most commonly used data structure in python.
4) In the list you can store different types of values like integer, string and float etc.
5) Support indexing and slicing
6) List is slower than tuple for interaction

- Tuple:
1) Tuple is written by ()
2) Tuple is immutable (Only you can view values of tuple hence it is immutable not perform any operation)
   Common Operations: 
   a) count(), index()
   b) min(), max(), sum()
3) Orderd / support indexing and slicing
4) Faster than list
5) Allows duplicate value

- Set:
1) Set is written by {} or set()
2) In set it will print only unique values / No duplicates
3) IN python set in unorderd, mutable 
   Common operations:
   a) add(), remove(), discard()
   b) union(), intersection(), difference()
4) Not for sequence this will print random unique values from set
5) No indexing (set[0]) is not allowed
6) Supports mathematical operations
7) Very fast

- Dictionary:
1) Dictionary is written by {key:value}
2) Key must be unique
3) values can be duplicated
4) ordered/ Mutable
5) No indexing (access via keys)
   Common operations:
   a) keys(), values(), items()
   b) get(), pop(), update()

- Points to be noted
List -> flexible
Tuple -> fixed
Set -> unique
Dictionary -> mapped data
